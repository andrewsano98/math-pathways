How to Use the Abacus

To add and subtract using the abacus, move beads toward the center beam to represent values. Beads touching the beam are counted, while beads away from it are not. Each column represents a place value (ones, tens, hundreds, etc.).

For example, if you want to add 851 + 235, you first represent 851 on the abacus. In the ones column, move 1 bottom bead. In the tens column, move 1 top bead. In the hundreds column, move 1 top bead and 3 bottom beads. Then add 235 using the same process. If a column exceeds 9, you carry the extra value into the next column. The result is 1086.

How do I subtract?

You start with the larger number already set on the abacus and subtract by removing beads from right to left. If a column does not have enough value, you borrow from the next column to the left.

Can I multiply or divide?

Yes, but these operations are performed through repeated addition and subtraction.

Decimal values can also be represented by shifting place values into fractional columns.
