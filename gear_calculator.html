How to Use the Pascaline

The Pascaline is an early mechanical calculator designed to perform arithmetic using rotating dials instead of manual computation. Each dial represents a single place value in a base-10 system (ones, tens, hundreds, and thousands).

To use the Pascaline, rotate each dial to select a digit from 0 to 9. When you release a dial, that value is added into its corresponding place value and automatically carried into the total display.

How do I calculate a number?

Start from the rightmost dial (ones place) and move leftward. Each dial contributes its digit multiplied by its place value. For example, setting 3-4-2-1 produces the number 3421.

What happens when a dial passes 9?

In a real Pascaline, gears would physically carry overflow into the next column. In this simulation, values are interpreted per dial position when released.

What can I do with it?

You can use the Pascaline to build numbers and explore place value. Future versions would support full addition and subtraction through mechanical carrying.
